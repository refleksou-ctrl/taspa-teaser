# Taspa teaser

Static one-page teaser, published with GitHub Pages. Hidden from search (`noindex` + `robots.txt`).

## Fonts
The public site uses stand-ins (Poppins, EB Garamond, Inter).
On a machine with the CVI fonts installed (ITC Avant Garde Gothic Pro Bold, Ashbury), the browser uses them automatically.
To test from font files instead, put them in `fonts/` (git-ignored, never published):
`head-bold.otf`, `sub-regular.otf`, `sub-italic.otf` (or `.woff2`).

## Placeholders
Opening date (fictional), email, phone, social links, EN version.
